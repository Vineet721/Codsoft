# CodSoft

CodSoft is a small web development portfolio repository containing three frontend projects built with HTML, CSS, and JavaScript. Each project demonstrates a clean, responsive design and practical web functionality.

## Projects

### 1. Calculator
- Folder: `calculator/`
- Description: A simple calculator application with basic arithmetic operations like addition, subtraction, multiplication, and division.
- Includes: `index.html`, `style.css`, `script.js`
- Use case: Practice DOM manipulation, event handling, and JavaScript logic for interactive UI.
- Live Demo : https:github.com/Vineet721/CodSoft/Calculator/

### 2. Landing Page
- Folder: `landingpage/`
- Description: A responsive landing page layout designed to showcase a product, service, or portfolio introduction.
- Includes: `index.html`, `style.css`
- Use case: Demonstrates page structure, visual styling, and responsive design.
- Live Demo : https:github.com/Vineet721/CodSoft/LandingPage/

### 3. Portfolio
- Folder: `portfolio/`
- Description: A personal portfolio website template for displaying skills, projects, and contact details.
- Includes: `index.html`, `style.css`, `asset/`
- Use case: A showcase template for developers or designers to present their work.
- Live Demo : https:github.com/Vineet721/CodSoft/Portfolio/

## How to Use

1. Open the folder for the project you want to view.
2. Open the `index.html` file in a browser.
3. For the calculator, interact with the buttons to perform calculations.
