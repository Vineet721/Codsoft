# Calculator

A simple web-based calculator project built with HTML, CSS, and JavaScript.

## Overview

This calculator supports basic arithmetic operations such as addition, subtraction, multiplication, and division. It demonstrates DOM event handling and JavaScript logic for button interactions.

## Files

- `index.html` - markup and calculator layout
- `style.css` - visual styling and responsive button layout
- `script.js` - calculator logic and input handling

## How to Use

1. Open `index.html` in a browser.
2. Use the buttons to enter numbers and operations.
3. Press `=` to compute the result.
4. Press `C` to clear the current entry.

## Notes

- No additional setup is required.
- The app works entirely in the browser.
