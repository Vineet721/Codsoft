# Portfolio

A personal portfolio website template built with HTML and CSS.

## Overview

This project is a portfolio webpage for showcasing skills, work, and contact information. It includes a clean design and sections for personal introduction, projects, and a contact area.

## Files

- `index.html` - portfolio content and page sections
- `style.css` - layout, styling, and responsive design
- `asset/` - image and media assets used by the portfolio

## How to Use

1. Open `index.html` in a browser.
2. Explore the portfolio sections and visual layout.
3. Replace sample content and assets with your own.

## Notes

- Fully static and easy to customize.
- Designed as a starter portfolio template.
